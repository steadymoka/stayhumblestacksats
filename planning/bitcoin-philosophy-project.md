# Bitcoin Philosophy-Driven Project Ideas

> "Don't trust, verify." — 비트코인의 정신

## 배경: 왜 철학이 중요한가

비트코인은 단순한 디지털 화폐가 아니다.
2008년 금융위기 속에서 태어난 비트코인은 중앙은행의 무분별한 화폐 발행,
정부의 자본 통제, 금융 시스템의 불투명성에 대한 **근본적인 의문**에서 출발했다.

오스트리아 학파 경제학 — 하이에크의 "화폐의 탈국유화", 미제스의 "건전화폐론" —
이 비트코인의 철학적 뿌리다. 프로젝트도 이 정신을 담아야 한다.

---

## 핵심 키워드

- **탈중앙화 (Decentralization)**: 누구의 허락도 필요 없는 네트워크
- **건전화폐 (Sound Money)**: 2,100만 개 고정 공급, 인플레이션 없는 화폐
- **자기주권 (Self-Sovereignty)**: "Not your keys, not your coins"
- **투명성 (Transparency)**: 모든 거래가 공개 원장에 기록
- **검열 저항 (Censorship Resistance)**: 누구도 거래를 막을 수 없음

## Project Idea: "The Bitcoin Observatory" (비트코인 관측소)

### 한줄 요약

비트코인 네트워크의 탈중앙화 건강 상태, 온체인 경제 활동, 그리고 법정화폐 대비 건전성을
한눈에 보여주는 **철학 중심의 대시보드**

### 왜 이 프로젝트인가

기존 비트코인 대시보드들은 "가격"에 집중한다.
하지만 비트코인의 진짜 가치는 가격이 아니라 **네트워크 그 자체**다.

- 풀노드가 몇 개 돌아가고 있는가? → 탈중앙화의 척도
- 사토시의 지갑은 여전히 잠들어 있는가? → 창시자의 철학
- 고래들은 무엇을 하고 있는가? → 부의 집중도와 분배
- 법정화폐는 얼마나 팽창하고 있는가? → 비트코인 존재 이유

이 모든 것을 **하나의 관측소**에서 보여주자.

### MVP 로드맵

**Phase 1 — Foundation (4주)**
- [ ] 프로젝트 셋업 (Next.js + API)
- [ ] Bitnodes API 연동 → 풀노드 수 + 세계지도 시각화
- [ ] 사토시 지갑 주소 목록 정리 + 잔액 조회
- [ ] 기본 대시보드 레이아웃

**Phase 2 — Whale Tracking (4주)**
- [ ] 고래 지갑 모니터링 시스템 구축
- [ ] 커뮤니티 기반 라벨링 시스템 (오픈 DB)
- [ ] 대량 이동 감지 + 알림 (Webhook/Telegram)
- [ ] 부의 분포 차트 (지니계수)

**Phase 3 — Sound Money (4주)**
- [ ] FRED API 연동 → 글로벌 M2 통화량 시각화
- [ ] 법정화폐 평가절하 비교 차트
- [ ] 비트코인 vs 국가 경제 규모 비교
- [ ] 오스트리아 학파 인용구 + 교육 콘텐츠

**Phase 4 — Community & Polish (4주)**
- [ ] 다국어 지원 (한국어/영어/스페인어)
- [ ] 사용자 커스텀 대시보드
- [ ] 모바일 반응형 최적화
- [ ] 오픈소스 기여 가이드 + 문서화
